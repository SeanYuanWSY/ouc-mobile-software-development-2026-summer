# 中国海洋大学 2026 夏《移动软件开发》

本仓库统一保存本课程各实验的小程序源码和实验说明。每个实验都是一个独立、可直接导入微信开发者工具的小程序，互不共享 `app.json`，避免配置和页面相互干扰。

## 目录结构

```text
.
├── lab01-hello-miniprogram/        # 实验一：第一个微信小程序
│   ├── app.json
│   └── README.md
├── lab02-business-card-miniprogram/ # 实验二：名片小程序
│   ├── app.json
│   ├── image/                       # 本实验的头图、头像等图片资源
│   └── README.md
└── README.md
```

## 如何运行

1. 打开微信开发者工具，选择“导入项目”。
2. 选择需要运行的实验目录，而不是本仓库根目录。例如，实验二选择 `lab02-business-card-miniprogram/`。
3. 点击“编译”即可预览对应实验。
