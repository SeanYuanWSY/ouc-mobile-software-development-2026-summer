# 部署配置

函数名 lab06_aiReview，入口 index.main，Node.js 16.13（当前云端实际运行时），内存 256 MB，执行超时 60 秒，允许公网访问。控制台超时配置独立于代码部署；部署后用 cloud_fn_info 核验。无需配置任何 DeepSeek 服务端 Key 环境变量。

必须先创建 lab06_ai_usage 并设为 ADMINONLY（客户端无读写权限），再启用函数。Key 仅用于当前请求 Authorization 头，不记录事件或原始异常。平台日志服务目前未启用，不因此承诺平台绝无诊断留存。计数仅保存哈希 ID、日期/分钟窗口与次数。

真实有效 Key 的调用需由使用者在小程序界面输入并确认，测试不得从其他应用提取 Key。详情见实验目录 README。
