# 验证说明

## 已有证据

- 官方 DevEco / Hvigor 工具完成 ArkTS 编译、资源处理与 HAP 打包。
- API 26 ARM 本地模拟器成功安装调试 HAP，并启动 EntryAbility。
- 四组逻辑检查共 249 项：数学 104 项、几何 63 项、函数曲面 35 项、角度模式 47 项。
- 覆盖优先级、非法输入、定义域、单位换算、方程与统计边界、三维投影、曲面采样及 DEG/RAD/Ans 往返。
- 2026-09-08 使用官方 uitest 操作模拟器并取得 11 张真实截图：`(12+8)×3=60`、同一 `sin(30)` 在 DEG/RAD 下的结果与高亮、自选底数 `log(2,8)=3`、1 GiB 转 GB、二次方程实根、8 项统计量、波纹及手动输入的马鞍函数曲面、几何体尺寸和历史页面。
- 强制停止并重新启动应用后，刚才的三条计算记录仍保留；历史页面展示算式、结果和角度模式。

在配置好本机工具路径后，可使用 `bash scripts/test.sh` 重跑四组测试。

## 验证边界

249 项测试是算法和模式逻辑检查，界面核对范围仅限上述实际操作。未逐一穷举所有按钮、所有单位和所有几何参数组合，不能据此宣称完整界面交互均已验收。

当前仅使用本地 API 26 ARM 手机模拟器，尚未验证真机、平板或旧版系统。HAP 为此模拟器接受的未签名调试包，未配置个人发布签名，不是应用商店发行包。

函数曲面使用有限网格近似，可能漏掉窄峰或未采中的奇点；采样高度范围不是解析极值。计算使用双精度浮点数，并非任意精度数学软件。
