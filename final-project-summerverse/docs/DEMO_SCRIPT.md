# 3 分钟答辩演示脚本

1. **0:00–0:20：空岛开场**  
   “普通日记保存内容，SummerVerse 会让真实记录长成一座岛；没有授权的数据保持为空。”

2. **0:20–0:55：一句话造岛**  
   输入：“昨晚和狗狗去海边散步 40 分钟，心情特别好。”AI 生成可编辑草稿，确认保存。

3. **0:55–1:20：一次记录，多处联动**  
   回到小岛看到陪伴区域出现；再打开时间轴和地图，展示同一数据自动联动。

4. **1:20–1:40：真实接口**  
   真机同步微信步数、位置天气；强调失败时绝不显示模拟值。

5. **1:40–2:10：时间电话**  
   选择暑假早期日期，问“你现在最担心什么？”展示日期之后的记忆被隔离。

6. **2:10–2:35：平行暑假**  
   改变一个真实选择，展示蓝色真实路线和橙色生成路线永久分栏。

7. **2:35–2:55：AI 导演**  
   生成分镜并播放几幕，照片来自真实记录，AI 只负责结构和旁白。

8. **2:55–3:00：结尾**  
   “别人保存暑假照片，我们让暑假里的自己继续住在一座由真实记忆长出的花园里。”
