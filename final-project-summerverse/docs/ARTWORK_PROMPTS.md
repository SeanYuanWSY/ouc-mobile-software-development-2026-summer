# SummerVerse AI 插图提示词

本轮插图使用统一的温暖水彩与手绘水粉质感，画面服务于手机端纵向卡片；避免 UI 文字、按钮、水印、边框和写实摄影感。以下是整理后的可复现提示词。

## 小岛三阶段

共同提示：`SummerVerse 暑假记忆小岛，温暖的儿童绘本水彩与水粉插画，奶油纸张质感，鼠尾草绿、蜂蜜黄、珊瑚橙配色，中央构图，柔和自然光，高细节，无文字、无 UI、无水印。`

- 初生：海面上一座刚萌芽的小岛，嫩芽、小帐篷、木栈桥和少量贝壳，留有较多呼吸空间。
- 成长：小岛长出花园、小屋、书本、树木与蜿蜒小路，生活气息丰富但不拥挤。
- 盛放：繁茂而明亮的夏日岛屿，花园、灯串、树屋、瀑布与远处帆船，呈现完成和庆祝感。

## SummerTwin 三阶段

共同提示：`同一个原创森林小精灵 SummerTwin，圆脸、棕色短发、叶片尖帽、绿色斗篷、珊瑚色围巾，温暖水彩绘本风，柔和纸张纹理，角色一致，无文字、无 UI、无水印。`

- 初生：小精灵蹲在一株幼苗旁，清晨花园稀疏、安静、充满期待。
- 成长：小精灵在茂盛花园里浇花，周围有书本、萤火虫和逐渐长高的植物。
- 盛放：小精灵站在成熟花园中央，繁花、灯串和温柔星光包围，画面有陪伴与成就感。

头像使用初生阶段插图中的角色近景裁切，保证聊天头像与花园角色一致。
