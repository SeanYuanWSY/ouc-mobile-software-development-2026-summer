# 隐私与可信设计说明

## 最小化采集

- 不做持续后台定位；路线仅连接用户保存事件时选择的地点。
- 不自动读取相册；只有用户点击“照片 / 视频”后才调用媒体选择器。
- 不自动录音；只有用户点击录音按钮才启动麦克风。
- 不自动读取微信运动；只有用户点击同步步数才请求授权。

## 真实数据与生成内容分层

### 事实层

用户记录或确认的日期、时间、标题、原文、媒体、地点，以及已授权接口数据。反思与示例不进入真实统计、地图或 AI 事实证据。

### 推断层

情绪总结、行为画像、洞察、时间电话回答、平行故事、导演旁白。

生成内容在 UI 中带有“AI”“推断”“生成路线”等标签，不会写回原始记忆，除非用户主动点击保存为反思记录。

## API Key

- 每位用户使用自己的 Key，仅在本次运行内存与输入框中保留，应用不主动写入 Storage、数据库或日志。
- 同意后，相关记忆文字、日期、心情、地点名称或所选照片经腾讯云发送给用户选择的 AI 服务商（自定义接口会显示接收地址）；Key 用于鉴权，由该账户承担 API 费用。
- 清除 Key 阻止后续调用，不撤销已发出的请求及费用。部署时需核对平台参数追踪，不能仅凭源码承诺平台永不留存。
- Git 检查脚本会扫描疑似 `sk-` 密钥。

## 用户数据归属

云端文档含 `_openid`，`dataService` 在服务端校验所有权。客户端数据库权限建议全部关闭，避免跨用户读取。

## 资料分析（含公开网页导入，1.1.0体验版已部署）

只读取用户通过微信选择器选择、通过文件打开入口传入或主动粘贴的资料，不读取完整群聊、聊天成员、消息历史或微信原生语音。TXT/MD和粘贴文字首次云保存前同样征求同意；拒绝时只留当前页面的未保存内容。本次运行内可复用明确说明范围的云保存同意。

用户可主动转入聊天网页或粘贴公开链接。链接先停留在页面，只有用户确认后腾讯云才访问；不携带Cookie、OPENID、模型Key或调用方请求头，不绕过登录、验证码、付费墙，也不加载脚本和子资源。服务端拒绝常见敏感查询参数，工作台只保存标题、域名和提取文字，不把输入URL作为元数据保存。网页正文作为不可信资料，若随后使用AI，只有这些白名单字段会进入模型输入；正文自身可能含链接。网页用途补充说明已准备但尚未提交公众平台，不能把源码告知视为平台隐私审核通过。

文档/图片经确认后临时上传腾讯云；提取文字、AI分析和手动确认的任务按用户保存至 `material_workspaces`，可在资料库删除，账号数据清理也包括该集合。代码不设过期自动删除；本机模式只存本机且不会自动迁移到云端。文档/图片导入完成或失败均尝试删除新上传的临时云文件，失败时提示，不承诺异常退出后的立即删除。

图片文字识别与资料分析另外征求发送至用户所选模型服务商的同意，使用用户会话 Key；图片识别会传图片，分析会传提取文字和问题。文件名及内容均作为不可信资料，模型没有工具执行权限。出处显示提取片段，可能不含原文版式，OCR存在错误可能，结论始终标为AI草稿。

用户主动导出结果时会在小程序本机目录生成文本文件，内容包括分析、出处与任务；只有用户进一步选择微信分享对象才会发送。导出文件、剪贴板和对外分享副本不随云端资料删除而自动撤回，请用户自行管理。

删除记忆或在编辑中移除附件时，程序会尝试清理不再被其他记忆或头像引用的本机、云端文件；仍被使用的文件会保留。如果附件清理没有全部成功，界面会明确提示。云端批量清理仍应由管理员定期审计，避免异常中断留下孤立文件。

## 发布责任

源码无法替代微信公众平台的隐私合规配置。发布者必须根据实际使用功能填写隐私保护指引、用途说明、第三方服务说明和数据删除机制。
# 外部助手连接（新增，待部署验收）

用户可在灵感收件箱主动创建有效期30天的连接凭证。默认仅允许外部助手投递AI草稿；用户另行授权后，才允许读取最近20条记忆正文及20项目标，这些内容将提供给用户自行配置的外部助手及其模型服务商。请仅连接可信工具。此凭证不同于模型API Key，数据库仅存摘要；离开页面不再显示原文。电脑端凭证由用户在自己私有配置中管理，不提交到代码仓库。

草稿须用户确认后才成为记录或目标。用户可随时断开连接，已投递草稿仍可自行处理；连接计数、状态及草稿目前保留用于限额、重复请求核对。外部接口不开放模型Key、头像、媒体附件及其他用户数据。当前功能尚待公网部署验收，具体边界见 `ASSISTANT_BRIDGE.md`。

## 电脑接力（1.1.0体验版，公网入口关闭，真实连接待验收）

接收手机任务是独立可选权限，不随旧连接自动开启。发起前展示具体连接、所选资料数量和字符数，并说明接收方包括用户自己的电脑助手及其配置的模型。仅发送用户勾选来源的文字片段与任务要求，不携带小程序模型Key、头像或其他记录；服务器固定这次工作台版本与资料范围。

任务快照、要求和AI结果保存在腾讯云，仅所有者与获准领取的指定连接按各自动作访问。用户可以在接力列表清除内容；清除后只保留权限、状态、时间及重复请求核对所需最小摘要。已采纳的结果仍有可访问列表入口，不会因新任务自动删除；上限20项，满额要求先明确清理。用户自行复制的文字、电脑文件和模型处理方持有的副本无法随云端清除而收回。

“采纳”表示用户已看过这份结果，不代表本地文件已真实修改、任务已完成或新增生活经历。外部客户端的工具和文件权限仍由用户在该客户端管理。当前没有自动后台读取、自动轮询或远程启动电脑。

## 界面与专注偏好

本机只额外保存界面模式、减少动效选项，以及专注计时所需的任务ID、时间与计时状态；不把资料正文或Key放进这些偏好。计时结束不会自动增加学习时长或完成任务。云连接失效时保持云端数据模式并提示重试，不切成本机副本。

## Cloudflare 中转计划（尚未启用，历史候选）

项目维护者已同意验证免费Cloudflare中转。若上线，外部助手的投递正文、连接令牌及用户主动允许读取的记忆正文会经过Cloudflare，再与腾讯云交换；不用于转发小程序模型API Key。当前仅完成本地入口处理器，未部署或传输实际数据。上线前须同步面向每位使用者的告知与公众平台说明，并验证平台日志配置。维护者授权不代替各用户的授权。
