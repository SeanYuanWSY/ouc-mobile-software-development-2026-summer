# 隐私与可信设计说明

## 最小化采集

- 不做持续后台定位；路线仅连接用户保存事件时选择的地点。
- 不自动读取相册；只有用户点击“照片 / 视频”后才调用媒体选择器。
- 不自动录音；只有用户点击录音按钮才启动麦克风。
- 不自动读取微信运动；只有用户点击同步步数才请求授权。

## 真实数据与生成内容分层

### 事实层

日期、时间、标题、原文、媒体、地点、步数、目标进度。

### 推断层

情绪总结、行为画像、洞察、时间电话回答、平行故事、导演旁白。

生成内容在 UI 中带有“AI”“推断”“生成路线”等标签，不会写回原始记忆，除非用户主动点击保存为反思记录。

## API Key

- 正式 Key：只放云函数环境变量。
- 临时测试 Key：只在当前小程序进程内保存，不写入 Storage。
- Git 检查脚本会扫描疑似 `sk-` 密钥。

## 用户数据归属

云端文档含 `_openid`，`dataService` 在服务端校验所有权。客户端数据库权限建议全部关闭，避免跨用户读取。

## 发布责任

源码无法替代微信公众平台的隐私合规配置。发布者必须根据实际使用功能填写隐私保护指引、用途说明、第三方服务说明和数据删除机制。
