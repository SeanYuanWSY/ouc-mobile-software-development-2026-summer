## 三、代码审核说明（提交前再核实运行结果）

本小程序为个人日常手账与成长记录工具，提供文字、图片、语音记录、时间轴检索和目标进度管理。首页小岛随真实记录数量成长。地图只展示用户主动保存的地点，不持续后台定位。

基础记录功能不需要 DeepSeek Key。AI 为可选增强功能，通过云函数使用用户在设置页自行填写的个人 API Key，相关 API 费用由该用户自己的服务账户承担。本项目不提供开发者共享 Key。AI 生成内容与真实记录明确区分；未连接时显示失败提示，不使用模拟回复冒充生成结果。

### 审核体验路径

1. 首页“记录”进入新增页，填写标题和正文并保存；在“轨迹”中检索，进入详情编辑或删除。
2. “成长”创建目标，点击进度按钮查看变化；查看真实记录统计。
3. “我的”进入 SummerTwin，打开“设置”；在用户同意后填写个人 Key 并测试连接，连接成功后再体验 AI。
4. 定位、相机、录音和微信运动均从对应按钮主动触发授权。
