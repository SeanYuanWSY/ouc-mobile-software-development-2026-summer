# 真机验收清单

## 基础流程

- [ ] 初次进入无记忆，不出现假步数、假天气或假地点。
- [ ] 新增纯文字记忆后：首页、时间轴、统计、Twin 花园同步变化。
- [ ] 修改记忆后所有页面更新。
- [ ] 删除记忆后所有页面减少。
- [ ] 本机模式关闭并重开后文字记忆仍存在。

## 媒体

- [ ] 相册图片可选择、预览、保存、重新打开。
- [ ] 相机拍照可保存。
- [ ] 视频可播放。
- [ ] 录音可开始、停止、上传并回放。
- [ ] 拒绝权限时有可理解的提示。

## 位置与地图

- [ ] `wx.chooseLocation` 返回真实名称、地址和坐标。
- [ ] Marker 点击后能定位到对应记忆。
- [ ] `wx.openLocation` 能打开微信地图。
- [ ] 多地点路线按时间连接。
- [ ] 没有地点时不显示示例路线。

## 微信运动

- [ ] 真机首次调用出现 `scope.werun` 授权。
- [ ] `weRunData` 云函数日志能看到一次调用。
- [ ] 今日步数与微信运动一致。
- [ ] 拒绝授权时首页显示“未授权”。

## DeepSeek

- [ ] 云函数环境变量 Key 可通过“测试连接”。
- [ ] 临时 Key 在关闭小程序后消失。
- [ ] 一句话记录返回合法字段并可编辑。
- [ ] AI 失败时表单仍可手动保存。
- [ ] 时间电话没有引用所选日期之后的记忆。
- [ ] 平行路线始终标注为生成内容。
- [ ] 导演章节使用存在的记忆 ID。

## 发布

- [ ] 完成公众平台隐私保护指引。
- [ ] 关闭 `ALLOW_CLIENT_API_KEY`。
- [ ] 数据库客户端读写权限关闭。
- [ ] 全部云函数部署到正式环境。
- [ ] 删除演示数据或保留明显“示例”标签。
