## 自动页面验收入口（2026-09-06）

`scripts/devtools-smoke.cjs` 使用已经安装的官方 miniprogram-automator 连接开发者工具。通过 AUTOMATOR_PACKAGE 指定该包的 package.json 绝对路径，DEVTOOLS_WS 指定本机自动化端口，QA_OUTPUT 指定结果目录。脚本不安装软件、不更改登录或云配置；只能在**空的隔离本地副本**运行，检测到云模式或已有记录/目标立即停止。

脚本操作真实页面，模拟的仅为测试确认弹窗。它创建有 QA_LOCAL 前缀的临时记录与目标，只删除本次已知 ID，成功结束时恢复空数据；中断时 fixture.json 保留 ID，须核对该 ID 后通过页面删除，不能清空用户存储。自动化截图/结果留在指定输出目录，不上传云端。

当前 SDK 适配从实际 systemInfo.SDKVersion 判断兼容性，原因是新版工具 Tool.getInfo 不返回旧库预期的 SDKVersion；这不修复也不模拟 AppID。最终微信身份、媒体权限和真实 AI 服务仍须分别验收。
